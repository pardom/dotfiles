Manage this dotfiles repository

Usage: stowaway <COMMAND>

Commands:
  host               Manage hosts
  module             Manage modules
  role               Manage roles
  show [HOST]        Show a host's roles and modules, and what's available
  switch [HOST]      Apply a host's configuration
  help [COMMAND]...  Print this message or the help of the given command

Options:
  -h, --help     Print help
  -V, --version  Print version
